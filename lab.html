Where do I configure cobwebs?+

Use the mod JAR, open settings with Right Shift or /kewisdistxt, and select Cobwebs beside Textures. Choose ON/OFF, a preset, layout and both colors. Open web color studio for the color wheel, brightness and hex entry. Select Use colors, then Apply. The Appearance tab also links to these controls. The standalone ZIP has the default white webs; the settings GUI requires the mod.

How do I open settings?+

Launch your Fabric profile for Minecraft Java 1.21.11 with kewisstxt-1.36.0.jar in that instance's mods folder. Enter a world or server, type /kewisdistxt in Minecraft chat and press Enter, or press Right Shift. If the command is unknown, check that you launched the Fabric instance containing the JAR and restart the game. The resource-pack ZIP alone supplies textures; settings and commands require the mod.

How does the shield finisher trigger?+

The client correlates your recent mace hit on a blocking shield with Minecraft's real item-break packet. Break packets do not identify the attacker. Totem and kill modes also require locally attributed damage and the same target within one second. Custom servers need to send the normal events.

Do I need to install anything on the server?+

No. KewissTxT is a client mod. The server does not need the mod or operator permissions.

Should I enable the ZIP with the JAR?+

The mod already includes its textures and Fabric API. Choose the JAR for settings, or the standalone ZIP for default textures. The mod now deselects its redundant standalone ZIP when both are enabled, so your settings control the result.

Can I keep the original weapon textures?+

Yes. Every weapon uses its original Minecraft texture and shape. Themes change the animated overlay. Adjust Overlay strength and Overlay size in Textures, or switch Animation OFF to show the clean original. Enchanted weapons only can limit where the animation appears.

What is included in the standalone ZIP?+

Original Minecraft item textures with the default Kewiss animation overlays, golden apples, theme-colored apple highlights and moving totem wraps, low fire, block texture borders, hotbar, vital icons and white outlined cobwebs. TierTagger, the shield finisher, clean hotbar-only orb renderer, GUI, themed combat effects, animated entities, sounds, projectile trails, HUD and conditional enchanted-only models require the mod JAR.
